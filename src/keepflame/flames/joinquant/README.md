# JoinQuant Flame

`mode = "inspect"`（默认）通过仓库外 Cookie 文件查询签到状态，未完成时提醒用户；`mode = "browser"` 使用独立浏览器会话，自动处理已识别的滑块布局并提交签到。两者都以账号任务状态接口的 `taskList.login.status = 1` 为完成依据。官方公开前端也据此判断已签到；尚未通过真实账号与页面交叉验证。

## 自动流程解决的问题

`browser.py` 先查状态，已完成就退出；未完成才点击唯一的“签到”按钮，捕获本次页面请求得到的挑战，避免拿旧图片回答新挑战。`matching.py` 在本机重建 33×2 块、363×142 像素的背景，对 56×56 拼块做去均值相关匹配。透明区域不参与匹配，置信度至少 0.90、与远离最佳位置的第二候选分差至少 0.04；图片、布局、坐标或匹配不明确就停止。以上阈值仅经合成图片验证，没有真实成功率数据。

验证 token 交给页面已有的 Vue `getToken` 回调；仅在本轮浏览器与原生请求处理的内存中使用，不记录或输出。当前实现依赖页面私有 DOM/回调，站点升级可能使其失效。每轮只回答一次，不刷新验证码穷举；回调后最多复查三次，只有后台已完成才成功。按钮消失、验证成功或请求发出均不是完成证据。实际签到请求必须通过 `guard.py` 的方法、路径、阶段、次数及 ruleKey=login 校验，其原生响应也必须确认成功；页面 fetch 返回值不能代替后台证据。HTTP 401/403/429 立即停止后续动作，502/503/504 不在本轮重试；有效的服务器冷却时间会延后调度。

60 秒是各步骤共享预算，不是操作系统级硬杀超时；浏览器启动上限 20 秒，单次页面请求上限 10 秒。Chrome 关闭和本地图片计算不属于可强杀的后台作业。失败至少等待 6 小时，会话问题至少 24 小时；核心还会应用每日窗口。CLI `run-once` 是显式即时尝试，会跳过等待。

## 专用会话接入

真实接入需批准明确账号与一次验收，开发测试无需账号。使用仓库外、当前用户所有的专用目录，权限只允许该用户（0700）。不得复用或复制日常 Chrome 配置，也不导出其 Cookie。目录内仅需一个非秘密登记文件 `.keepflame-profile.json`（0600）：

```json
{"version":1,"account_id":"primary","purpose":"keepflame"}
```

标签必须与 TOML 的 `account_id` 一致。登记文件用于防止误选目录，不证明网站上实际登录的是哪个账号；接入时仍需核对。程序不自动创建或认领现有目录，不读取密码文件。用户在该专用浏览器中完成官方登录/MFA 后关闭窗口，再进行 `run-once`。当前没有内建登录/登记 CLI；由接入执行者在获准后准备目录和专用登录入口，不要求用户在聊天中传密码、Cookie 或 token。到期后更新同一专用会话即可。

浏览器 capability 启用 Chromium sandbox，禁止下载、service worker 和 WebSocket；页面请求只放行所选 HTTPS 主机和它的 `cdn.` 主机。真实站点若需要额外资源域名，须先核实必要性再缩小范围增加，不为成功而默认开放所有域名。浏览器目录本身含敏感会话，须留在用户本机，不能提交或打包。

先用 `config/keepflame.browser.example.toml` 创建不提交的个人配置，安装 `uv sync --extra browser --dev`，确认本机 Google Chrome。默认 Docker 镜像不含浏览器依赖。自动模式无需 `cookie_file`；查询模式仍使用原 Cookie 流程。

## 验证与参考

单元测试覆盖确认标准、一次提交、失效/限流中止、退避、隐私错误信息和目录登记。选择性 Chrome 测试从空临时会话运行，页面及所有 HTTP 响应均由进程内合成，DNS 禁止外部解析，不连接聚宽、不加载真实账号。

```bash
.venv/bin/python -m pytest
KEEPFLAME_SYNTHETIC_BROWSER=1 .venv/bin/python -m pytest tests/test_joinquant_browser.py
```

参考 [joinquant-auto-skill 的固定提交](https://github.com/youngyunxing/joinquant-auto-skill/tree/7bd0b9e343f0dc3dbf9ce54c8416e39a871c0003) 的协议布局与调用顺序，未运行或复制上游脚本。该版本 `package.json` 声明 ISC，但没有独立 LICENSE 文件；当前为独立实现。上游自报可用、合成本地验收和真实稳定签到是三种不同证据。本项目尚缺最后一项，不包含上游的其他积分任务、密码处理或 CDP 端口扫描。

查询模式保留 15 秒 HTTP 超时、安全网关/网络错误最多两次请求、429 不立即重试、服务器冷却下限及不同人工操作类型。任一模式的 Cookie、token、认证页面都不得进入 Git、日志、SQLite 或真实账号 fixture。

自动执行阶段的精确接口预算、原生响应关联及官方公开源码依据见 [PROTOCOL.md](PROTOCOL.md)。交互登录使用独立阶段，不安装签到请求门控；自动 Keeper 不执行登录。profile 校验只遍历元数据，拒绝内部数据软链接/硬链接及非本用户内容，保留 Chrome 根目录正常 Singleton 锁链接；该检查不能阻止同一用户的进程在检查后修改目录。
