# Flames

这里存放需要被维持的具体平台插件。每个 Flame 使用独立子目录，在内部封装认证、状态检查、页面或响应解析以及维持动作。

只有开始实现某个平台时才创建其目录；插件可以自由组合 HTTP、浏览器或 Telegram 等能力，但必须向核心返回统一结果。

当前实现有 `joinquant/`、`ikuuu/` 和 `tushare/`。`joinquant/` 处理聚宽签到与阅读；`ikuuu/` 用人工导入的 Cookie 完成 ikuuu 每日签到并自动发现可用域名；`tushare/` 用人工导入的 Cookie 完成 Tushare 每日签到、浏览上新和猜涨跌三项积分任务。三者都把验证码和会话更新保留为人工操作，不包含绕过安全验证的逻辑。
